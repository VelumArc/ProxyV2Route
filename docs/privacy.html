Privacy, explained.

What Proxy V2Route processes and where it stays.说明 Proxy V2Route 处理哪些信息，以及信息保存在哪里。

Proxy V2Route’s use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

Proxy V2Route 对用户数据的使用遵守 Chrome Web Store 用户数据政策，包括 Limited Use（有限使用）要求。

Privacy / 隐私

Profiles and preferences stay in the browser; imported nodes and their credentials stay in the local companion. These records are not sent to the developer. Browser traffic follows the applied browser proxy. No analytics or result history is collected by the extension.

情景和界面偏好保存在浏览器中；导入节点及其账密保存在本机组件中，不上传给开发者。浏览器流量经过所选代理；扩展不收集统计，也不保留检测历史。

Export profiles includes the selected nodes' runtime configurations, credentials and resolved predecessor paths in a local JSON download. This also includes nodes scanned from the local client. Import restores those nodes to the destination's private library with new local ports. Unused nodes, subscription URLs and tokens, local installation paths and measurement history are not included. Backups include each profile's last saved route and destination policies, including their addresses and referenced nodes. Saved configurations for its inactive basic, predecessor and chain modes stay in this browser and are not included in the portable backup. Backups are not encrypted; protect the downloaded file and share it only with trusted recipients.

导出情景会将所用节点的运行配置、账号密钥及完整前置链路写入本地下载的 JSON，也包含从本地客户端扫描的节点。导入后保存到目标电脑的私有节点库，并重新分配本地端口。不包含未使用节点、订阅链接和令牌、本机安装路径或检测历史。备份包含各情景最近保存的线路、策略匹配地址及所引用的节点；基础、前置和链式模式中未启用的已保存配置保留在当前浏览器，不包含在可迁移备份中。备份文件未加密，请妥善保管，仅向可信接收者提供。

Opening the popup or IP workspace, successfully switching routes, or requesting status triggers bounded exit-IP checks through ipify. Ping0 reports require optional site access. IP tools pre-fill the current browser exit IP; Globalping sends the displayed target to up to three probes in the selected region only after Start, including a China option. Probe availability varies; ICMP loss alone does not establish filtering. Domain checks use GreatFire. FAST.com is a separate embedded speed provider. Each provider receives normal connection data and handles it under its own privacy policy.

打开弹窗或 IP 工具页、成功切换线路或执行状态检查时，会向 ipify 发起有时限的出口 IP 检测。Ping0 报告需允许对应站点访问。IP 工具默认填写当前出口 IP；Globalping 点击开始才向所选区域的最多三个探针发送目标，支持选择中国；可用探针会变化，ICMP 丢包本身不能证明被墙。域名检测使用 GreatFire，FAST.com 为独立嵌入测速站点。服务商会接收常规连接信息，并按自身政策处理。

Website tests contact only selected, visible public homepages/icons after Start, with four concurrent credential-free requests at most. A response confirms browser reachability, not account access, HTTP success or regional unlocking. Timeouts and browser restrictions may produce an unconfirmed result.

网站列表点击开始后才检测当前分类中勾选的地址，最多四个并发请求、不携带账号凭据。收到响应不代表账号可用、HTTP 成功或地区解锁；超时和浏览器限制都可能导致无法确认。

Cloudflare speed tests use small HTTP latency samples and selected 10/50/100 MiB download/upload limits. Both mode transfers up to the selected size in each direction. Per-second rates and final results remain in dialog memory. Closing or hiding the page cancels local tests; already submitted remote measurements may finish at the provider.

Cloudflare 测速包含少量 HTTP 延迟样本，以及每项 10/50/100 MiB 的下载、上传上限。双向模式每个方向各使用所选流量。每秒速率和结果只保存在弹窗内存；关闭或隐藏页面会取消本地测试，已提交的远端测量可能仍在服务商处完成。

Optional scripting access may be used in a user-visible or background first-party Ping0 tab after a direct report read fails. The extension reads only bounded report text and original website links and never solves challenges, clicks verification controls, logs tokens or exports cookie values. If the background path is unavailable or verification is required, the original Ping0 page opens in a normal tab for the user. Verification remains user-controlled.

直接读取报告失败后，可选脚本权限仅用于用户可见或后台打开的 Ping0 原站标签页，读取有界的报告文字和原始官网链接；不点击验证、不代答验证、不记录或导出令牌或 Cookie。后台路径不可用或需要验证时，自动打开 Ping0 原网页新标签页，由用户自行完成验证。

A failed popup connectivity check does not prove the selected node is offline: the check endpoint, current browser proxy setting or browser restrictions may fail independently. 弹窗检测失败不等于节点离线，也可能是检测端点、浏览器代理设置或浏览器限制导致。

In basic, predecessor and chain modes, per-layer diagnostics run a separate temporary local core only after Test is clicked. They contact api.ipify.org through each cumulative path, do not change the active route and delete temporary credentials/configuration after each bounded probe. Results identify a failed path boundary, not proof that a single server is offline.

基础、前置和链式模式的逐层链路检测仅在点击检测后启动临时本地核心，通过各段累积路径访问 api.ipify.org；不更改当前使用线路，每次有时限的探测结束即清理临时配置和凭据。失败表示该路径边界未连通，不能单凭它断定某台服务器离线。

Closing an IP tool unloads its frame and cancels local requests. Chrome uses the browsingData permission to clear HTTP cache and CacheStorage for that tool's exact allowed origin, then waits before reopening. This also affects cached resources from the same origin in other tabs, but does not clear other sites or cookies, passwords, localStorage, IndexedDB or Service Worker registrations. Third-party CDN caches are not included. Firefox cannot safely scope this cache API, so it unloads the tool and reports that cache deletion is unsupported.

关闭 IP 工具会卸载网页并取消本地请求。Chrome 使用 browsingData 权限，仅清理该工具允许来源的 HTTP 缓存和 CacheStorage，重开前等待完成；同一来源在其他标签页的缓存也会受影响。不会清理其他网站、Cookie、密码、登录存储或 Service Worker 注册，也不包含外部 CDN 的缓存。Firefox 无法安全限定该缓存接口的站点范围，因此仅卸载工具并提示不支持缓存删除。

Node-library tests contact Cloudflare through the selected node and inherited predecessor chain. Full tests transfer the selected 10/25/50/100 MiB in each direction; group totals are shown before starting. Results stay in the open workspace. Temporary authenticated test cores and configuration are removed when the owned native session closes. Node lists and proxy credentials are not sent as test payloads.

节点库测速通过所选节点及其继承前置链路访问 Cloudflare。完整测速每个方向使用所选 10/25/50/100 MiB，开始前显示分组总量；结果仅保存在当前工作区内存。所属本地会话关闭时回收临时认证核心和配置；不会把节点列表或代理账密作为测速内容发送。

Subscription URLs and tokens are saved only in the private companion database. The extension stores only whether user-enabled updates exist and a shared browser alarm. Refresh contacts the subscription provider using the chosen policy; proxy-first attempts direct access only after the proxy attempt fails. The provider receives normal request information, including its subscription token and the network address used to reach it. Updates use the shared browser alarm.

订阅链接及令牌只保存于组件私有库；扩展只缓存是否启用自动更新并使用一个共享浏览器定时器。更新按所选策略请求订阅服务商，代理优先仅在代理失败后直连；服务商会接收其订阅令牌、请求信息和访问来源地址。更新使用共享浏览器定时器。
