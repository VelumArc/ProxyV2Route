# Website catalog / 网站连通列表

The bundled catalog contains 52 public websites grouped by AI, development, video/music, social, mainland and common services. Category references include the [V2Fly community domain lists](https://github.com/v2fly/domain-list-community/blob/master/data/category-ai-!cn). Tests use only selected entries and request public icons without login credentials; a response does not establish account access or regional unlocking.

本地目录按 AI、开发工具、视频音乐、社交、国内服务和常用服务分组，固定收录 52 个网站。分类参考 V2Fly 社区域名列表。仅检测勾选条目，访问公开图标且不携带登录凭据；收到响应不代表账号可用或地区解锁。
